Preparação do ambiente

Faça isto antes de 21 de setembro

ImportanteNão deixe para o primeiro dia

A instalação do brms compila código C++ e pode levar de 10 a 40 minutos na primeira vez, dependendo da máquina e da conexão. Se você chegar na segunda-feira sem isso pronto, vai perder a prática do Encontro 8.

Se travar em algum passo, mande um e-mail antes do curso: diogo.provete@ufms.br.

1. R e RStudio

Instale, nesta ordem:

  1. R ≥ 4.4 — https://cran.r-project.org
  2. RStudio Desktop — https://posit.co/download/rstudio-desktop/
  3. Quarto ≥ 1.5 — https://quarto.org/docs/get-started/

Se você já tem R instalado há mais de um ano, atualize. Vários pacotes que usaremos (glmmTMB, brms, DHARMa) exigem versões recentes.

Compilador C++

O brms precisa compilar modelos. Antes de instalá-lo:

  • macOS: abra o Terminal e rode xcode-select --install.
  • Windows: instale o Rtools na versão correspondente ao seu R, a partir do CRAN.
  • Linux: instale build-essential (Debian/Ubuntu) ou o grupo de ferramentas de desenvolvimento da sua distribuição.

2. Pacotes

Rode o bloco abaixo no console do R. Ele instala apenas o que estiver faltando.

pacotes <- c(
  # manipulação e visualização
  "tidyverse", "here", "janitor", "palmerpenguins", "patchwork",
  "GGally", "ggeffects", "broom", "broom.mixed", "knitr", "rmarkdown",
  # modelos lineares e GLM
  "car", "emmeans", "MASS", "performance", "see", "sjPlot", "marginaleffects",
  # versão bayesiana dos mesmos modelos
  "loo", "bayesplot",
  # GLMM, zeros inflados e ordinais
  "lme4", "glmmTMB", "DHARMa", "ordinal", "pscl", "lmtest",
  # seleção de modelos
  "MuMIn", "AICcmodavg",
  # raciocínio causal
  "dagitty", "ggdag"
)

faltando <- setdiff(pacotes, rownames(installed.packages()))
if (length(faltando)) install.packages(faltando)

brms e Stan — o passo demorado

Usamos o brms do Encontro 2 em diante, sempre ao lado do modelo frequentista equivalente. A razão de ser ele, e não outro pacote bayesiano, é que a sintaxe é idêntica à do lme4 e do glmmTMB: y ~ x + (1 | grupo) significa a mesma coisa nos três. Você aprende uma notação só.

O preço é que o brms compila um programa Stan para cada modelo novo. Por isso ele precisa de compilador C++ e de paciência na primeira execução.

install.packages("brms")   # puxa rstan e StanHeaders

Teste a compilação com um modelo mínimo. A primeira execução demora; as seguintes, não.

library(brms)

teste <- brm(mpg ~ wt, data = mtcars, chains = 2, iter = 1000, refresh = 0)
summary(teste)

Se summary() imprimir uma tabela com Rhat igual a 1.00, está pronto.

DicaAlternativa mais rápida: cmdstanr

Se a instalação do rstan der problema — o que acontece com alguma frequência no Windows —, o caminho alternativo é o cmdstanr, que baixa um Stan pré-compilado. As instruções oficiais estão em https://mc-stan.org/cmdstanr/. Depois, use backend = "cmdstanr" nas chamadas a brm().

3. Verificação

Rode este bloco e confira se nenhuma linha acusa falha:

essenciais <- c("tidyverse", "lme4", "glmmTMB", "DHARMa", "emmeans",
                "performance", "MuMIn", "ordinal", "brms")

resultado <- vapply(essenciais, function(p) {
  ok <- requireNamespace(p, quietly = TRUE)
  cat(sprintf("%-12s %s\n", p, if (ok) "OK" else "FALTANDO"))
  ok
}, logical(1))

if (all(resultado)) cat("\nAmbiente pronto.\n") else cat("\nInstale os pacotes marcados como FALTANDO.\n")
